# Архитектура проекта

## Назначение
Проект собирает данные Google Trends по заранее заданным нишам, сохраняет raw-данные и пишет audit log.

## Основные слои
- `data/manifests/` — конфигурация ниш
- `data/raw/` — сырые CSV-файлы
- `data/audit/` — журналы выполнения
- `core/` — общая логика
- `jobs/` — точки входа и сценарии запуска

## План MVP
1. Одна ниша
2. Один timeframe
3. Один raw CSV
4. Один audit log
