# Google Trends DE Pipeline

DE-проект для сбора, хранения и подготовки данных Google Trends по нишам.

## Цель проекта
Собрать сильный portfolio-проект для позиции Data Engineer:
от получения данных из внешнего источника до их сохранения, логирования и дальнейшей подготовки к аналитике.

## Что планируется в проекте
- чтение конфигурации ниш из `niche.json`
- получение данных из Google Trends
- сохранение raw CSV
- audit logging в JSONL
- batch processing по нескольким нишам
- подготовка clean layer
- дальнейшая загрузка в БД
- оркестрация через Airflow

## Почему этот проект важен
Проект показывает не просто парсинг, а подход Data Engineering:
- работа с внешним источником данных
- управляемая конфигурацией обработка
- понятная структура хранения
- логирование
- развитие от MVP к production-like решению

## Статус
В разработке. Текущий этап: проектирование структуры репозитория и MVP ingestion-слоя.

## План развития
1. Оформить структуру проекта
2. Реализовать `pull_one.py` для одной ниши и одного timeframe
3. Добавить raw storage и audit log
4. Сделать batch processing
5. Добавить clean layer
6. Подготовить Airflow orchestration
